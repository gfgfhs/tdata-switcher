# tdata-switcher

Быстрый переключатель папок **tdata** и запуск **Telegram Portable**.

- 🪟 **Окно с аккаунтами**: поиск, двойной клик — и Telegram открыт
- 🖥️ **Ярлыки на рабочий стол** для каждого аккаунта (с иконкой Telegram)
- 🏷️ **Цветные метки**: создавай свои («Работа», «Личные», «Клиенты»…), вешай на любые аккаунты, фильтруй одним кликом
- 📦 **Импорт из zip / rar / 7z**: выбрал архив, и tdata сама разложилась по папкам
- ⌨️ **Командная строка**: `--run`, `--import`, `--shortcut`, `--list`

## Как работает

1. Запускаешь `tdata_switcher.exe`: откроется окно со списком аккаунтов
2. Дважды кликаешь по аккаунту (или Enter) → открывается Portable с этим аккаунтом
3. Новые аккаунты добавляются кнопкой **«Импорт архива…»** или копированием папок в `tdata/`

Никакого копирования файлов — используется официальный флаг `-workdir`.

## Структура

```
tdata-switcher/
├── tdata_switcher.exe      ← окно (GUI)
├── tdata_switcher_cli.exe  ← текстовое меню (консоль)
├── Telegram/
│   └── Telegram.exe        ← Portable с desktop.telegram.org
└── tdata/
    ├── account1/
    │   └── tdata/          ← классика
    ├── account2/
    │   └── tdata/
    └── account3/           ← или сразу содержимое tdata (key_datas ...)
```

Готовые `.exe` лежат в разделе [Releases](../../releases) вместе с `SHA256SUMS.txt`.
Исходники: `tdata_switcher.py` (точка входа и CLI), `tdata_gui.py` (окно), `tdata_core.py` (вся логика).

## Окно

| Действие | Как |
|---|---|
| Запустить аккаунт | двойной клик, **Enter** или кнопка «Запустить» |
| Найти аккаунт | просто печатай: поле поиска активно сразу (**Ctrl+F**, **Esc**: очистить) |
| Метки аккаунта | кнопка «Метки ▾» (**Ctrl+L**) или правая кнопка → «Метки»: галочки у нужных, можно сразу у нескольких выделенных |
| Фильтр по меткам | клик по цветной плашке над списком; несколько плашек = аккаунты со **всеми** этими метками; «Без метки» показывает неразмеченные |
| Ярлык на рабочий стол | кнопка «Ярлык на рабочий стол» (можно выделить несколько: Ctrl/Shift) |
| Импорт архива | кнопка «Импорт архива…» или **Ctrl+I** (можно выбрать несколько файлов) |
| Открыть папку аккаунта | правая кнопка мыши |
| Обновить список | **F5** |

Галочка «Закрывать окно после запуска» запоминается. Если `Telegram.exe` не найден, программа попросит указать его и запомнит путь.

## Метки

Метка = название + цвет. У одного аккаунта может быть сколько угодно меток, одна метка может висеть на многих аккаунтах.

- **Создать:** «Метки ▾ → Новая метка…»: вводишь название, выбираешь цвет из палитры или «Другой цвет…» (любой). Если перед этим были выделены аккаунты, метка сразу ставится на них
- **Поставить / снять:** выдели аккаунт(ы) → «Метки ▾» → галочка у нужной метки
- **Изменить, переименовать, удалить:** «Метки ▾ → Управление метками…» (двойной клик по метке = изменить). При удалении метка снимается со всех аккаунтов
- **Видно сразу:** цветные квадратики рядом с именем аккаунта, названия меток в отдельной колонке, плашки-фильтры со счётчиками
- **Поиск** (`Ctrl+F`) ищет и по именам аккаунтов, и по названиям меток

Метки лежат в `tdata/labels.json` рядом с аккаунтами. Это обычный JSON: его можно бэкапить, переносить вместе с папкой и править руками.
Метки привязаны к имени папки аккаунта, поэтому при переименовании папки метки нужно поставить заново.

## Ярлыки

Ярлык `Telegram - <имя>` на рабочем столе запускает конкретный аккаунт одним кликом, без окна и консоли
(внутри: `tdata_switcher.exe --run "<имя>"`). Иконка берётся у `Telegram.exe`.
Если перенесёшь папку программы, ярлыки нужно создать заново.

## Импорт из архивов

Поддерживаются **zip** (без доп. программ), **rar** и **7z** (нужен [7-Zip](https://www.7-zip.org/) или WinRAR;
подойдёт и встроенный в Windows 10/11 `tar.exe`, но 7-Zip надёжнее).

- Внутри архива tdata ищется сама, в любой вложенности: `tdata/…`, `Telegram Desktop/tdata/…` или просто `key_datas` в корне
- Один аккаунт в архиве → папка называется как архив (`Ivan.zip` → `tdata/Ivan/tdata/`)
- Несколько аккаунтов → имена берутся из папок внутри архива
- Имя занято → добавляется суффикс `_2`, `_3`, существующие аккаунты не перезаписываются
- Архив с паролем → программа спросит пароль
- Защита: пути вида `../` и символические ссылки из архива отбрасываются, размер распаковки ограничен

## Командная строка

```
tdata_switcher.exe                          # окно
tdata_switcher.exe --run "Ivan"             # запустить аккаунт и выйти (имя, начало имени или номер)
tdata_switcher.exe --import Ivan.zip --import Petr.rar --password 1234
tdata_switcher.exe --shortcut "Ivan"        # ярлык на рабочий стол (--shortcut-all для всех)
tdata_switcher_cli.exe --list               # список аккаунтов (с метками)
tdata_switcher.exe --label-add "Работа=#539bf5"   # создать метку (цвет необязателен)
tdata_switcher.exe --tag Ivan Работа        # поставить метку аккаунту (--untag снимает)
tdata_switcher.exe --label-remove Работа    # удалить метку
tdata_switcher_cli.exe                      # текстовое меню (i — импорт, s N — ярлык, q — выход)
tdata_switcher.exe "D:\my_tdatas"           # другая папка с аккаунтами (или --root)
```

`tdata_switcher.exe` собран без консоли, поэтому вывод команд (`--list` и т.п.) смотри через `tdata_switcher_cli.exe`.

## Запуск из Python

Нужен Python 3.9+ (для окна: с tkinter, он есть в стандартной установке для Windows).

```
python tdata_switcher.py                # окно
python tdata_switcher.py --cli          # текстовое меню
python tdata_switcher.py "D:\my_tdatas" # с другой папкой
```

## Сборка .exe

Локально:

```
build.bat
```

Получатся `dist\tdata_switcher.exe` (окно) и `dist\tdata_switcher_cli.exe` (консоль).

**Релиз через GitHub Actions:** тесты и сборка запускаются на каждый push и pull request, а чтобы выпустить релиз:

```
git tag v1.1.0
git push origin v1.1.0
```

Actions соберёт оба `.exe`, посчитает SHA256 и приложит всё к новому релизу.

## Безопасность

- `tdata` = **полный доступ к аккаунту**. Не отправляй эти папки и архивы посторонним и не коммить их (`.gitignore` уже закрывает `tdata/`)
- Скачивай `.exe` только из Releases этого репозитория и сверяй хэш с `SHA256SUMS.txt`

## Примечания

- Telegram Portable нужно скачать с [https://desktop.telegram.org/](https://desktop.telegram.org/) (Portable version)
- Один и тот же auth-key нельзя держать открытым одновременно в нескольких клиентах
- Скрипт запоминает последний выбранный аккаунт (файл `last_account.json`)
